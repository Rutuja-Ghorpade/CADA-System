🛡️ Child Abuse Detection & Alert System

A smart IoT-based system designed to detect signs of child abuse and instantly alert guardians using real-time sensor data and location tracking.

🔧 Hardware Used
- ESP32 – Core microcontroller
- FSR Sensor – Detects External force apply on Child Body
- GSR Sensor – Monitors stress through skin conductivity
- MAX30100 – Pulse oximeter for heart rate & oxygen level
- GPS Module – Tracks child's live location
- SOS Button – Allow child to trigger  the alert manually
- Blynk App – Mobile app to view data & receive alerts

📲 How It Works
1. Sensors collect vital signs and stress indicators.
2. Data is processed by ESP32 and sent to Blynk.
3. If abnormal readings or SOS trigger detected:
   - 📍 Location is shared
   - 🚨 Alert is sent via Blynk notification

✅ Features
- Real-time monitoring
- Location-based alerts
- Manual SOS option
- Mobile access via Blynk app

🧠 Idea Behind
To create a system that helps in early detection of potential child abuse and ensures quicker response for child safety.
